# Archipelago Doom Worlds Index

This is an index of stable, tested APWorlds created for _Archipelago Doom 2.0_. This repository intends to give worlds that are fully playable and tested a stable home off of Discord.

If you have created a world and would like to see it added to this repository, please submit an [Issue](https://github.com/ArchipelagoDoom/worlds/issues) or a [Pull Request](https://github.com/ArchipelagoDoom/worlds/pulls). Note that we have a couple of requirements for worlds hosted here:
 - At the bare minimum, your world must not have any unreachable exits or locations without assigned regions. (If this is the case, not only will you be warned when creating the APWorld itself, there will also be warnings given when using it to generate a game.)
 - For entirely new worlds, a few test games will be played to make sure the logic of the world is functional.
 - Extra details like names for individual locations and custom level selects are nice to have, but are not required.

Installing a New World

Archipelago Doom 2.0 uses the same APWorld format as Archipelago itself; the same APWorld file is used both for generating a randomized game through Archipelago, and playing that game with Archipelago Doom.
To add a new game to Archipelago Doom:
  • Create a "games" folder in the directory where Archipelago Doom is installed, if it doesn't already exist.
  • Copy the APWorld into that "games" folder.
  • Start the Archipelago Doom Launcher. The newly added world should now appear in the games list.

APWorld Manager

This index can also be added to the APWorld Manager, if you would like to use it to browse for new worlds and updates.
To add this index to the APWorld Manager:
  • Open the "host.yaml" file in your Archipelago Installation.
  • Find the apworld_manager section.
  • Under repositories, add the following line:
    • https://archipelagodoom.github.io/worlds/index.json: true
